# Theo Agent OS — releases

Installers and the auto-update feed for **Theo Agent OS**, the macOS menu-bar
app that connects your Mac's coding agents to the Theo Agent desk.

- Download: https://www.opencharts.com/download/theo-agent-os/mac
- Each release is tagged `theo-agent-os-vX.Y.Z` and carries
  `TheoAgentOS_X.Y.Z_universal.dmg`, the stable alias `TheoAgentOS-macOS.dmg`
  (what the download link resolves to), the updater bundle + its signature,
  and `latest.json`.
- The app polls `releases/latest/download/latest.json` for updates.
- Releases are published by the `theo-agent-os-release` workflow in the main
  OpenCharts repository.
